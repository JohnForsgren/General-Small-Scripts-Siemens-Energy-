# Development log

- Implemented `counter.py` as shared local scanner using pypdf; PDF total excludes DOCX pages. DOCX metadata page counts are shown as potentially outdated. Unreadable/password-protected PDFs count as documents and make PDF total incomplete.

- `build.py`: bundles pypdf into a single-file `.pyz` (recipient needs Python 3.10+), and builds a Windows GUI EXE with PyInstaller (`--exe`, recipient needs no Python). Outputs in `dist/`; run `python build.py --exe` to rebuild. See README for user-facing instructions.
