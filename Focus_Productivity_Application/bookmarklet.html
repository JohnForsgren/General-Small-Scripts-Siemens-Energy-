YouTube Focus Bookmarklet

If your company blocks extension installation, this page generates a bookmarklet you can save as a normal browser bookmark.

Drag apply bookmarklet Drag remove bookmarklet

How to use

  1. Open this file in Chrome.
  2. Drag the link to your bookmarks bar, or copy the code into a bookmark URL.
  3. Open YouTube and click the bookmarklet to toggle focus mode.
